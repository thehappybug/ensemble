# Acme API Tools

Acme API Tools is a fictional company used for this demo. We help developer-tool
companies turn an OpenAPI description into reliable, idiomatic SDKs and an API
developer portal. Our product combines SDK generation, documentation, API change
checks, and a release workflow that keeps SDKs in sync with an API.

We sell to engineering and product teams whose public API is becoming a product
surface. Our strongest value propositions are shorter integration time, fewer
support requests caused by SDK drift, and consistent SDK releases across languages.
We do not sell a coding agent. Describe these as fictional capabilities; never
invent customer results, partnerships, usage statistics, or product guarantees.

For outreach, connect one verified prospect signal to one relevant capability.
Ask for a short discovery conversation rather than promising a result.
