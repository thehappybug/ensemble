The cache contains a real `dagre-d3-es@7.0.14` archive (MIT). It was extracted for
inspection to `/tmp/ensemble-dagre-d3-probe`. Its `src/dagre/index.js` exports
`layout`, and `src/graphlib/index.js` exports `Graph`; these depend on `lodash-es`.
Its main entry exports graphlib, intersections, and an SVG renderer, rather than
the `@dagrejs/dagre` public API. This is a possible explicit alternative, not an
installed substitute or a verified UI implementation.

The available esbuild API can build source without tsup or Vite in this limited
environment, while normal builds should retain their documented dependency
chain. Browser rendering and missing library installation remain separate
checks. Fresh-clone instructions should continue to include
`npx playwright install chromium`, since a new machine may lack the browser.
